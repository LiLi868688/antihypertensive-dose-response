# Antihypertensive Dose-Response Analysis

A small, fully reproducible, version-controlled data-analysis project that studies a
**synthetic** Phase I dose-response dataset for a hypothetical antihypertensive drug.
The main deliverable is a Jupyter notebook that loads the data, computes descriptive
statistics, fits a linear dose-response model, and visualizes the result.

> **Note on data:** The patient-level numbers in `data/dose_response.csv` are synthetic
> and were generated for demonstration purposes only. They do not represent real
> clinical trial results and must not be used for medical decision-making.

## Repository contents

| Path | Description |
| --- | --- |
| `drug_response_analysis.ipynb` | Main Jupyter notebook: the full analysis and results |
| `data/dose_response.csv` | Synthetic input dataset (dose vs. systolic blood-pressure reduction) |
| `figures/dose_response_curve.png` | Figure generated by the notebook |
| `requirements.txt` | Pinned Python dependencies for reproducibility |
| `.gitignore` | Ignore rules for Python/Jupyter artifacts |

## Getting started

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd <repository-name>
   ```

2. Create and activate a virtual environment (recommended):

   ```bash
   python -m venv .venv
   source .venv/bin/activate        # Linux/macOS
   .venv\Scripts\activate           # Windows
   ```

3. Install the pinned dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start Jupyter and open the notebook:

   ```bash
   jupyter notebook drug_response_analysis.ipynb
   ```

Run all cells with **Kernel → Restart & Run All**. The notebook reads the local CSV file,
so no network access is required and the results are fully reproducible.

## Analysis summary

The notebook reports:

- Descriptive statistics for dose and systolic blood-pressure reduction.
- An ordinary least-squares (OLS) linear fit `y = slope * dose + intercept`.
- The coefficient of determination (R²) as a goodness-of-fit measure.
- A scatter plot of the observed values with the fitted regression line.
